# 3. MyWorld Task Manager - 플러그인 설계 및 구현 명세서

이 문서는 기존 옵시디언(Obsidian) 보관소 내에 흩어져 있던 CSS 스니펫과 Templater 스크립트를 하나의 독립적인 **TypeScript 기반 옵시디언 플러그인**으로 완결성 있게 이식 및 고도화한 시스템 아키텍처 명세서입니다.

---

## 1. 프로젝트 개요 및 기획 의도

*   **플러그인명**: MyWorld Task Manager (`myworld-task-manager`)
*   **기획 배경 (의존성 제로화)**: 기존 시스템은 `Templater` 스크립트를 사용하므로 사용자가 수동 관리해야 했으나, 이를 플러그인 자체 시스템으로 내재화하여 초기 사용자 경험(UX)을 극대화합니다.
*   **개발 목적**:
    1.  데일리 스케줄 노트와 프로젝트 개별 파일 간의 정밀한 **양방향 할 일(Task) 동기화** 구현.
    2.  📅 날짜 라벨을 분석하여 **디데이 우선순위 마커 자동 계산 및 트리형 정렬** 처리.
    3.  하루 마감 시 **루틴 버튼 리셋, 월간 통계 테이블 누적, 주간/월간 통계 그래프 아카이빙** 자동화.
    4.  노트 양식(Template) 내장 및 원클릭 생성을 통한 셋업 마법사 지원.
    5.  **[최신] 멀티 윈도우(팝아웃 창) 렌더링 지원 및 고도화된 모달 UI 제공.**

---

## 2. 핵심 기능 요구사항 명세 (Functional Requirements)

### [기능 A] 양방향 할 일 동기화 (Task Sync)
*   **동작**: 스케줄 노트 내 `# Project` 섹션의 링크를 스캔하여 대상 프로젝트 파일을 식별합니다. 스케줄 노트에서 수정한 상태(`[x]`)와 텍스트를 프로젝트 파일의 `# 실행` 구역 블록 ID(`^id`)에 덮어씁니다. 
*   **[최신] 완벽한 작성일/수정일 추적**: 태스크 생성 및 변경 시 내부 인덱싱 규칙을 통해 일자를 정확하게 동기화하고 트래킹합니다.
*   **완전 소거 (`//`)**: 텍스트 끝에 `//`를 붙이고 동기화 시 양쪽 문서에서 라인 자체를 완벽하게 삭제(Splice)합니다.

### [기능 B] 디데이 계산 및 자동 정렬 (D-Day & Sorting)
*   **동작**: 📅 날짜 라벨을 읽어 `[!]`, `[0]`, `[1]` 등의 커스텀 마커를 자동 갱신합니다. 부모의 마커를 자식에게 하향 전파하며, **긴급도 순위 -> 마감 날짜 순**으로 문맥을 보존한 채로 자동 정렬합니다.

### [기능 C] 하루 일과 리셋 및 통계 아카이빙 (Daily Reset & Archive)
*   **동작**: 리셋 명령어 실행 시 회고 입력창을 팝업하고, 체크된 루틴을 이모지(🟦🟩🟨🟥)로 변환해 월간 표에 이관합니다.
*   **데이터 무결성 방어**: 동적 헤더 매핑으로 템플릿 칸 이름이 달라도 매칭하며, 에러 발생 시 2-Phase Commit 롤백으로 파일 파괴를 방지합니다.

### [기능 D] 빠른 할 일 캡처 (Quick Capture)
*   **동작**: ✏️ 버튼 클릭 시 옵시디언 전용 입력 모달이 팝업되며, 입력된 내용을 메인 스케줄 문서의 `# Todo` 아래에 즉시 주입하고 자동 정렬 로직을 트리거합니다.

### [기능 E] 시스템 셋업 헬퍼 및 커스텀 UI (Setup & GUI)
*   **[최신] 부팅 시 동기화 모달 (StartupSyncModal)**: 앱 시작 시 미처리된 스케줄을 감지하여 안전하게 동기화를 제안하는 모달 창 렌더링.
*   **[최신] 캘린더 UI 팝업**: 달력 위젯(Calendar Widget)을 CodeMirror6 데코레이션 및 읽기 모드/Dataview로 띄워, 직관적인 날짜 픽킹 및 변경을 지원.
*   **[최신] 정밀 인터랙션 필터링**: 읽기 모드(Reading View)에서 일반 Todo 항목의 텍스트 클릭 시 체크박스 오작동 토글을 방지하여 텍스트 선택성을 보장하고, DataviewJS(`scRender.js`) 내 📅 날짜 클릭을 통한 실시간 날짜 수정 및 양방향 동기화를 지원. 

### [기능 F] 팝아웃 창(멀티 윈도우) 및 렌더링 완벽 지원 (Windowing)
*   **동작**: 라이브 프리뷰 포커스 버그, 팝업 창 내 키 이벤트 누수, 다중 창 렌더링 컨텍스트(`getActiveFile()` 의존성 제거 및 `MarkdownView` 기반 타겟팅) 문제를 모두 해결하여 어느 창에서 편집하든 동기화와 UI가 100% 정상 작동합니다.

### [기능 G] 중요 할 일 시스템 (Important Task System)
*   **체크박스 불변 원칙**: 체크박스 마커는 옵시디언 표준인 `- [ ]` (미완료)와 `- [x]` (완료)만을 100% 유지하여, 마커 변형으로 인한 체크 풀림 버그를 원천 차단합니다.
*   **데이터 원문 식별자(`⭐`) 보존 & 화면 은닉**: 마크다운 파일 원문에는 `⭐` 식별자가 저장되어 검색성 및 데이터 무결성을 보장하며, 화면(Live Preview, Reading Mode, Dataview)에서는 `.myworld-hidden-star`를 통해 `display: none`으로 깔끔하게 숨겨집니다.
*   **`[D]` 디데이 뱃지 골드 네온 빛남 (Glow Effect)**: 체크박스 겹침을 원천 배제하기 위해 좌측 보더 대신 디데이 뱃지(`.dday-virtual-badge.is-important`)에 골드 네온 발광(`text-shadow: 0 0 6px #f59e0b, 0 0 12px rgba(245, 158, 11, 0.7)`)을 부여하여 체크박스와 간섭 없이 즉각적이고 고급스러운 시각 효과를 제공합니다.
*   **달력 팝업 슬림 1-Click 컨트롤 (3버튼 액션)**: 날짜 라벨(📅 YYYY-MM-DD) 클릭 시 열리는 235px 슬림 달력 팝업 하단에 `[ 삭제 ]`, `[ 중요 ]`, `[ 오늘 ]` 3개 버튼을 배치하여, 단 한 번의 조작으로 날짜 설정/삭제 및 중요도 토글을 원자적으로 처리합니다.

## 4. 시스템 아키텍처 및 세부 구현 설계

### 물리적 파일 구조
```
myworld-task-manager/
├── src/
│   ├── main.ts            # 플러그인 진입점 (명령어 및 리스너 등록)
│   ├── settings.ts        # 설정 화면 (GUI 설정 필드 구성 및 템플릿 생성 헬퍼)
│   ├── TaskUtils.ts       # 디데이 마커 연산, 트리 구조 정렬, 텍스트 파싱 헬퍼
│   ├── Synchronizer.ts    # 탭 전환 자동 동기화 처리 및 진행도 바 업데이트
│   ├── ResetManager.ts    # 루틴 리셋, 이모지 이관 및 아카이브 대시보드 조립
│   ├── TemplateHelper.ts  # 템플릿 양식 주입, PARA 및 제텔카스텐 폴더 트리 생성
│   ├── Constants.ts       # 내부 정규표현식, 날짜 포맷팅 등 전역 상수 집합
│   └── ui/
│       ├── CalendarWidget.ts    # 라이브 프리뷰 대응 인라인 달력(Date Picker) 위젯
│       └── StartupSyncModal.ts  # 부팅 시 어제 일정 동기화 제안 모달 창
├── styles.css             # 빌트인 디자인 스타일시트 (팝아웃 지원, 루틴 칩 등)
├── manifest.json          # 플러그인 메타데이터 (ID, 버전 정보 등)
├── versions.json          # 버전별 최소 옵시디언 요구사항
├── package.json           # 노드 빌드 의존성 및 esbuild 스크립트 모음
└── esbuild.config.mjs     # esbuild 컴파일 설정 
```

### 세부 모듈별 구현 상세 로직
1.  **`main.ts`**: `Plugin` 클래스 진입점. CM6 위젯, 다중 윈도우 지원 리스너, `StartupSyncModal` 렌더링 호출.
2.  **`settings.ts`**: 표준 옵시디언 컴포넌트를 적용한 설정 화면. 피드백 링크 및 토글 가능한 개발 업데이트 공지 렌더링.
3.  **`TaskUtils.ts`**: 날짜 파싱 및 트리 정렬(Sort). 최근 프로젝트 오늘 할 일 추출 알고리즘 버그 픽스 반영.
4.  **`Synchronizer.ts`**: 다중 창 지원을 위해 `MarkdownView` 인스턴스를 직접 추적하여 양방향 동기화 처리 및 진행도 HTML 바 렌더링.
5.  **`ResetManager.ts`**: 루틴 이관 및 아카이브 조립.
6.  **`CalendarWidget` & UI**: 라이브 프리뷰와 읽기 모드 환경의 텍스트 매칭 및 DOM 이벤트 제어를 완벽 분리하여 설계.
