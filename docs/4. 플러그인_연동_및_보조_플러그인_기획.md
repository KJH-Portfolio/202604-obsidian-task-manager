# MyWorld Task Manager - 연동 및 보조 플러그인 활용 기획서

이 문서는 **MyWorld Task Manager** 플러그인의 구동 편의성을 높이고, 옵시디언(Obsidian) 생태계의 대표적인 플러그인들과 시너지를 극대화하기 위한 보조 플러그인 연동 가이드 및 기획서입니다.

---

## 1. 연동 플러그인 요약 및 포지셔닝

우리가 개발할 플러그인은 **"프로젝트 노드와 데일리 스케줄 간의 구조적 양방향 싱크, 루틴 리셋, 그리고 주기적 아카이빙 엔진"**에 특화되어 있습니다. 아래 플러그인들과 함께 사용하면 뷰(View)의 강력함과 편의성이 한층 배가됩니다.

| 플러그인 이름 | 권장 수준 | 플러그인과의 연동 및 시너지 역할 |
| :--- | :---: | :--- |
| **Advanced URI** | **필수** | 마크다운 내 HTML 단축 버튼을 통한 플러그인 백그라운드 명령 실행 |
| **Obsidian Tasks** | **권장** | 보관소 전체의 날짜별 할 일 실시간 조회(Query) 및 상호 보완적 뷰 제공 |
| **Daily Notes** | **권장** | 매일 첫 실행 시 오늘 날짜의 데일리 스케줄 노트 자동 생성 |
| **Style Settings** | **선택** | 둥근 루틴 버튼 및 디데이 컬러 마커 스타일의 GUI 설정 편집 연동 |

---

## 2. 세부 플러그인 연동 및 시너지 기획

### ① Advanced URI (명령어 단축키 버튼화)
*   **연동 목적**: 스케줄 관리 노트 상단에 정의된 단축 버튼들(⚡️, 🌤️, 🗂️ 등)과 프로젝트 노트 상단의 📤 버튼은 마크다운 본문에 HTML로 렌더링되어 있습니다.
*   **동작 매커니즘**:
    *   버튼 클릭 시 옵시디언 고유 프로토콜을 호출하여 플러그인 명령어를 실행합니다.
    *   예시:
        *   `obsidian://advanced-uri?commandid=myworld-task-manager:task-manage` (수시 동기화 버튼)
        *   `obsidian://advanced-uri?commandid=myworld-task-manager:daily-task-reset` (하루 리셋 버튼)
*   **플러그인 설정 기획**: 플러그인 내 [Setup Wizard] 실행 시, 생성되는 템플릿 마크다운 파일에 플러그인의 고유 Command ID가 적용된 HTML 링크 버튼이 자동으로 삽입되어 생성되도록 설계합니다.

### ② Obsidian Tasks (날짜 기입/수정/삭제 편의 및 쿼리 엔진)
*   **연동 목적**: Obsidian Tasks 플러그인은 할 일을 작성하거나 편집할 때 팝업 모달(Task Edit Modal) 창을 통해 **날짜(📅 마감일, 🛫 시작일 등)와 우선순위를 극도로 편리하게 기입, 수정, 삭제**할 수 있는 강력한 사용자 인터페이스(UI)를 제공합니다. 아울러 작성된 전역 할 일들을 조건별로 긁어모아 보여주는 실시간 쿼리(Query) 기능도 수행합니다.
*   **상호 보완적 시너지**:
    *   **Tasks 플러그인의 역할**: 단축키나 모달 창을 통해 개별 할 일의 메타데이터(📅 마감일 등)를 손쉽게 추가, 편집, 삭제하는 관리 UI를 담당합니다.
    *   **우리 플러그인의 역할**: Tasks 플러그인 등으로 손쉽게 기입된 📅 날짜 정보를 감지하고, 오늘 날짜와의 차이를 연산하여 **디데이 우선순위 마커(#D-0, #Past 등)를 자동 갱신**합니다. 그 후 마커 우선순위 및 마감일 순서대로 할 일 줄을 자동 정렬하며, 프로젝트와 스케줄 문서 간의 물리적인 양방향 동기화 및 마감 리셋(아카이빙)을 담당합니다.
    *   **화면 구성 및 UX 예시**: 사용자가 스케줄 관리 노트에서 Tasks 단축키를 눌러 마감일을 손쉽게 지정/수정하면(Tasks 플러그인 기능), 우리 플러그인의 수시 동기화 명령이 이를 감지하여 해당 할 일을 기한 순서대로 바로 정렬하고 프로젝트 본문 파일에 상태를 실시간 반영합니다.

### ③ Daily Notes (자동화된 하루 시작)
*   **연동 목적**: 옵시디언 코어 기능인 데일리 노트를 활성화하여 사용자가 옵시디언을 열 때 자동으로 오늘 날짜 파일이 생성되도록 유도합니다.
*   **연동 기획**:
    *   사용자가 Daily Notes 플러그인 설정의 "Template file path" 경로를 우리 플러그인이 생성한 `데일리 스케줄 템플릿.md` 경로로 지정하게 안내합니다.
    *   이로써 매일 아침 옵시디언을 켤 때마다 자동으로 루틴 버튼들과 프로젝트 대시보드가 갖춰진 오늘의 스케줄 시트가 열리게 됩니다.

### ④ Style Settings (비코딩 스타일 제어)
*   **연동 목적**: 사용자가 CSS 코드를 직접 수정하지 않고도 스타일을 변경할 수 있도록 합니다.
*   **연동 기획**:
    *   우리 플러그인이 로드하는 `styles.css` 내에 Style Settings가 인식할 수 있는 전용 CSS 변수 선언 주석을 빌트인합니다.
    *   이를 통해 사용자는 옵시디언 설정 -> Style Settings 메뉴 내에서 **루틴 가로 칩 버튼의 테두리 두께, 완료 투명도 수치, 디데이 컬러 바의 파스텔톤 색상 변경** 등을 슬라이더와 컬러 피커로 손쉽게 편집할 수 있게 됩니다.
