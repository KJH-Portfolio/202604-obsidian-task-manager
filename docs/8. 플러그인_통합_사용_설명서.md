# 📖 MyWorld Task Manager 플러그인 통합 사용 설명서

환영합니다! **MyWorld Task Manager**는 옵시디언 내에서 파편화된 할 일(Task)들과 스케줄 관리를 중앙 집중화하고, 일일 루틴과 월간 통계를 완벽하게 자동화해 주는 강력한 코어 플러그인입니다. 기존의 복잡했던 템플레이터(Templater) 스크립트들을 모두 제거하고, 클릭 한 번으로 스마트한 지식 관리 체계를 굴려보세요.

---

## ⚙️ 1. 초기 셋업 가이드 (최초 1회)

플러그인을 처음 설치하셨다면 아래 순서대로 뼈대(구조)를 먼저 잡아주세요.

### Step 1. 플러그인 설정창 열기
1. 옵시디언 설정(톱니바퀴) > `커뮤니티 플러그인` 탭에서 **MyWorld Task Manager**가 켜져 있는지 확인합니다.
2. 켜져 있다면, 하단의 플러그인 설정 메뉴에서 **MyWorld Task Manager**를 클릭하여 설정창으로 진입합니다.

### Step 2. 지식 관리 시스템 (PARA & 제텔카스텐) 셋업
플러그인 설정창의 **[2. 지식 관리 시스템 구축 헬퍼]** 구역을 확인해 주세요.
*   **`[PARA 구조 생성]` 버튼**: 아직 보관소에 `1. Project`, `2. Area`, `3. Resource`, `4. Archive` 폴더가 없다면 이 버튼을 클릭하세요. 깔끔한 폴더 구조와 사용 설명서가 즉각 생성됩니다.
*   **`[제텔카스텐 구조 생성]` 버튼**: `5. Zettelkasten` 폴더가 없다면 클릭하세요. 생각의 씨앗을 보관할 수 있는 3단계 메모 폴더 구조가 세팅됩니다.

### Step 3. 기본 템플릿 생성하기
설정창의 **[3. 기본 환경 및 파일 생성 헬퍼]** 구역을 확인해 주세요.
*   **`[기본 템플릿 노트 생성]` 버튼**: 데일리 스케줄 템플릿과 프로젝트 템플릿을 만듭니다. 클릭 시 **경로 입력창**이 팝업되며, 원하는 폴더(예: `3. Resource/01.Templates`)를 입력하면 해당 위치에 생성됩니다.
*   **`[스케줄 관리 노트 생성]` 버튼**: 매일 아침에 열어볼 핵심 관제탑 노트인 `스케줄 관리.md` 파일을 생성합니다.

> [!TIP] 기본 설정 경로 확인
> 설정창 상단의 **[1. 경로 설정]** 탭에서 지정된 경로들이 실제 생성된 폴더 이름들과 잘 맞는지 확인해 주세요! (기본값으로 두셔도 무방합니다.)

## 🎛️ 2. 핵심 워크플로우 및 버튼 조작법 (Daily Routine)

스케줄 관리 노트 상단에 있는 아이콘 버튼들과 프로젝트 노트의 버튼을 활용하여 매일매일의 루틴을 진행합니다.

### ⚡️ 수시 동기화 버튼 (번개 아이콘)
*   **어디서 누르나요?**: 데일리 스케줄 노트 상단
*   **무슨 일을 하나요?**: 
    1. 스케줄 노트의 `# Project` 밑에 적혀있는 링크들(`[[프로젝트A]]` 등)을 읽어들여서 원본 프로젝트 파일을 찾습니다.
    2. 스케줄 노트에서 내가 수정한 글자나, 완료 표시(`[x]`)를 원본 프로젝트에 동일하게 **덮어쓰기(반영)** 합니다.
    3. 반대로 원본 프로젝트 파일의 `# 실행` 구역에 새로운 할 일이 추가되어 있다면, 그 내용을 스케줄 노트로 **가져옵니다**.
    4. 할 일의 날짜를 계산해 디데이 마커(`[0]` 등)를 달고, 우선순위에 맞게 할 일들을 촥 정렬해 줍니다.

### ✏️ 빠른 할 일 캡처 버튼 (연필 아이콘)
*   **어디서 누르나요?**: 데일리 스케줄 노트 상단
*   **무슨 일을 하나요?**: 
    *   어디 따로 적어둘 필요 없이 팝업 창이 뜹니다.
    *   "우유 사기"라고 적고 엔터를 치면, 스케줄 노트의 `# Todo` 섹션 바로 아래에 `- [ ] 우유 사기`가 실시간으로 추가됩니다. 
    *   추가됨과 동시에 ⚡️동기화 버튼을 누른 것처럼 날짜 마커 계산과 정렬도 한 번에 자동으로 해줍니다.

### 🌤️ 하루 리셋 및 마감 버튼 (구름 아이콘)
*   **어디서 누르나요?**: 데일리 스케줄 노트 상단
*   **무슨 일을 하나요?**: 
    1. 오늘 하루 동안의 회고와 내일의 목표를 적는 창이 뜹니다.
    2. 확인을 누르면, 상단 `# 루틴` 구역 표에 오늘 체크했던 내용(색깔 이모지)을 쏙 빼내서 맨 밑의 `# 체크리스트` 거대 표의 오늘 날짜 칸에 영구 저장합니다.
    3. 내일 다시 체크할 수 있도록, 눌려있던 모든 루틴 버튼(체크박스)을 텅 빈 상태(`[ ]`)로 원상복구 시킵니다.
    4. 완료된 할 일들을 청소하고, 10일 치 통계 그래프를 다시 그려주며 통계 기록장(`4. Archive` 폴더)으로 보냅니다.

### 🗂️ 통계 수동 아카이빙 버튼 (폴더 아이콘)
*   **어디서 누르나요?**: 데일리 스케줄 노트 상단
*   **무슨 일을 하나요?**: 원래 이 작업은 하루 리셋(🌤️)을 할 때 자동으로 처리되지만, 만약 10일 구간이 끝나는 날에 통계를 미리 파일로 빼내어 백업하고 싶을 때 수동으로 강제 실행하는 버튼입니다.

### 📋 임시 메모 버튼 (클립보드 아이콘)
*   **어디서 누르나요?**: 데일리 스케줄 노트 상단
*   **무슨 일을 하나요?**: 길고 방대한 아이디어를 임시로 쏟아낼 백지 노트(`임시 메모.md`)를 즉시 엽니다. 파일이 없으면 알아서 만듭니다.

### 📤 스케줄 반영 버튼 (내보내기 아이콘)
*   **어디서 누르나요?**: **각 개별 프로젝트 노트** 상단
*   **무슨 일을 하나요?**: 프로젝트 노트 안에서 열심히 기획과 계획을 수정한 뒤, 그 내용을 메인 스케줄 노트로 밀어 넣습니다. (스케줄 창으로 전환할 필요 없이 바로 푸시할 수 있습니다.)

## 🛠️ 3. 스케줄 노트 수정 권한 (커스텀 가이드)

플러그인이 자동으로 문서를 썼다 지웠다 하기 때문에, "절대 건드리면 안 되는 이정표(헤더)"와 "사용자가 마음대로 커스텀해도 되는 곳"이 명확히 구분됩니다.

### ⛔ [절대 금지] 건드리면 고장 나는 부분
이 부분들은 플러그인이 인식하는 표지판입니다. 글자나 띄어쓰기가 바뀌면 플러그인이 길을 잃습니다.
1. **대분류 헤더 이름들**: `# Todo`, `#### 할 일`, `#### 프로젝트`, `# Project`, `# 루틴`, `# 체크리스트`, `# 통계`, `# 계획`, `# 실행`
2. **할 일 끄트머리에 붙는 블록 아이디 (`^xxxxxx`)**: 동기화를 위한 고유 식별자입니다. 지우면 동기화가 풀립니다.
3. **마크다운 표의 뼈대 기호 (`|`)**: 파이프 기호를 지우면 표가 깨져 통계 누적이 불가합니다.

### ✅ [자유 수정] 내 마음대로 바꿔도 되는 부분
표지판과 식별자만 건드리지 않는다면, 그 안의 '내용물'은 100% 당신의 마음대로 커스텀 가능합니다.
1. **루틴 표의 '열(항목) 이름' 맘대로 바꾸기**: 상단 미니 표와 하단 마스터 표의 이름만 똑같이 맞춰주면, '독서', '명상' 등으로 마음대로 고쳐도 플러그인이 알아서 인식하고 통계를 쌓습니다.
2. **할 일 내용과 체크 상태 자유 변경**: 내용을 수정하거나 체크 박스 안에 `x`, `-`, `>` 등을 넣어도 완벽하게 인식됩니다.
3. **`# 루틴` 콜아웃 내부의 텍스트**: 명언이나 목표 텍스트들은 마음대로 지우거나 고쳐 써도 지장 없습니다.
4. **할 일의 위치(순서) 이동**: 각 할 일 끝에 `^식별자`만 온전히 달려있다면 순서를 마음대로 바꿔도 문제 없이 동기화됩니다.

## 🎨 4. 나만의 루틴(표) 커스텀하기 (상세)

**[핵심 꿀팁: 상단 표와 하단 표 분리 운영]**
스케줄 노트를 보면 **① 제일 상단의 얇은 미니 표(입력용)**와, 맨 밑의 **② `# 체크리스트` 거대한 마스터 표(통계 보관용)** 두 개가 있습니다.
*   **칸 수를 맞출 필요가 전혀 없습니다!** 플러그인이 이름표(헤더)를 읽고 알아서 똑똑하게 매칭하여 데이터를 옮겨줍니다.
*   **추천 세팅**: 매일 눈으로 봐야 하는 ① 상단 미니 표는 '독서', '운동' 등 핵심 3~4개 칸만 남겨서 얇게 쓰시고, ② 하단 마스터 표에는 가끔씩 체크하는 '영양제', '병원' 등의 칸을 10개씩 길게 늘려서 보관하셔도 완벽하게 연동됩니다.

## 💡 5. 작동 메커니즘 (고급 심화)

플러그인의 스마트한 내부 로직을 이해하면 훨씬 편하게 쓸 수 있습니다.

### 📅 기한(D-Day) 자동 계산과 하향 전파
*   할 일 뒤에 `📅 2026-06-10` 처럼 달력 이모지와 날짜를 적어두고 ⚡️동기화를 누르면 플러그인이 기한 마커(`- [3] 책 읽기`)를 자동으로 달아줍니다.
*   **[핵심]**: 부모 태스크에 기한이 걸려있으면, 그 아래 들여쓰기 된 자식 태스크들도 부모의 기한을 똑같이 물려받습니다!

### 🗑️ 간편 완전 삭제 마법 (`//`)
*   완료 처리(`[x]`)를 하면 통계나 기록장(계획 탭)에 남습니다. 아예 흔적도 없이 영구 삭제하고 싶다면 할 일 텍스트 맨 뒤에 **`//`** 를 적어주세요. (예: `- [ ] 취소할 작업입니다 // ^a1b2c3`)
*   ⚡️동기화나 🌤️하루 리셋을 누르면, 메인 스케줄과 원본 프로젝트 양쪽 모두에서 흔적도 없이 영구 삭제됩니다.

### 🎯 긴급도 기반 자동 정렬
*   동기화나 퀵 캡처를 실행하는 순간, 플러그인이 기한 마커를 읽어들여서 **`[!] (기한 지남) ➡️ [0] (오늘) ➡️ [1] (내일) ➡️ ... 기한 없음`** 순서대로 알아서 예쁘게 착착 정렬해 줍니다.

## 🚨 6. 자주 묻는 질문 (FAQ) 및 에러 해결

*   **Q. 하루 리셋을 눌렀는데 에러가 떴다고 나옵니다!**
    *   **A.** 스케줄 노트 내부의 헤더(예: `# Todo`) 이름이 훼손되었을 가능성이 큽니다. 에러가 나더라도 플러그인의 **'트랜잭션 롤백'** 기능이 작동하여 파일을 리셋 직전 원본 상태로 완벽히 되돌려 놓습니다. 헤더 이름 확인 후 다시 시도해 주세요.
*   **Q. 과거의 Templater 스크립트(.js, .md 파일들)는 지워도 되나요?**
    *   **A.** 네! 완전히 지우셔도 됩니다. 플러그인이 모든 기능을 더 빠르고 안전하게 대체합니다.
*   **Q. 표를 수정하다가 모양이 깨졌어요.**
    *   **A.** 옵시디언 표는 `|` 기호로 칸이 구분됩니다. 표를 수정하실 때 `|` 기호가 지워지지 않도록만 주의해 주세요.
