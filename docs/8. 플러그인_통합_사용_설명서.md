# 📖 MyWorld Task Manager 플러그인 통합 사용 설명서

환영합니다! **MyWorld Task Manager**는 옵시디언 내에서 파편화된 할 일(Task)들과 스케줄 관리를 중앙 집중화하고, 일일 루틴과 월간 통계를 완벽하게 자동화해 주는 강력한 코어 플러그인입니다. 기존의 복잡했던 스크립트들을 모두 제거하고, 캘린더 팝업 및 멀티 윈도우까지 지원하는 강력한 기능을 한 번에 누리세요!

---

## ⚙️ 1. 초기 셋업 가이드 (최초 1회)

### Step 1. 플러그인 설정창 열기
1. 옵시디언 설정(톱니바퀴) > `커뮤니티 플러그인` 탭에서 **MyWorld Task Manager**가 켜져 있는지 확인합니다.
2. 켜져 있다면, 하단의 메뉴에서 **MyWorld Task Manager**를 클릭하여 설정창으로 진입합니다.

### Step 2. 지식 관리 시스템 (PARA & 제텔카스텐) 셋업
설정창의 **[2. 지식 관리 시스템 구축 헬퍼]** 구역을 확인해 주세요.
*   **`[PARA 구조 생성]` 버튼**: 보관소에 `1. Project` ~ `4. Archive` 폴더 구조를 자동 생성합니다.
*   **`[제텔카스텐 구조 생성]` 버튼**: `5. Zettelkasten` 메모 폴더 구조를 생성합니다.

### Step 3. 기본 템플릿 생성하기
설정창의 **[3. 기본 환경 및 파일 생성 헬퍼]** 구역을 확인해 주세요.
*   **`[기본 템플릿 노트 생성]` 버튼**: 경로 입력창이 팝업되며 템플릿을 생성합니다.
*   **`[일간 스케줄 노트 자동 생성]` 버튼**: 매일 아침 열어볼 관제탑 역할인 오늘의 일간 스케줄 노트를 자동 생성합니다.

## 🎛️ 2. 핵심 워크플로우 및 버튼 조작법 (Daily Routine)

### 🚀 [NEW] 부팅 시 동기화 안내 모달 (Startup Sync Modal)
옵시디언을 켤 때 어제 마무리하지 못한 스케줄 동기화가 있다면 앱 중앙에 팝업창이 부드럽게 뜹니다. 원클릭으로 간편하게 밀린 일정을 동기화하고 상쾌하게 아침을 시작할 수 있습니다.

### 📅 [NEW] 캘린더 위젯 UI (직관적인 날짜 선택)
더 이상 날짜(예: `2026-06-10`)를 일일이 키보드로 타자칠 필요가 없습니다! 할 일 텍스트 끄트머리에 생기는 캘린더 아이콘 버튼을 클릭하면 세련된 달력 UI 팝업이 뜹니다. 여기서 마우스 클릭만으로 날짜를 손쉽게 고르면 자동으로 할 일 우선순위가 계산되어 정렬됩니다.

### ⚡️ 100% 백그라운드 자동 동기화 (Background Sync)
*   **어디서 누르나요?**: **누르실 필요가 없습니다! (수동 버튼 폐지)**
*   **기능**: 과거에 있었던 수시 동기화 버튼은 플러그인의 탭 전환 엔진이 도입되면서 완전히 제거되었습니다. 스케줄 노트나 프로젝트 노트에서 글을 수정한 뒤, **다른 탭(창)을 클릭하거나 포커스를 이동하기만 하면 0.1초 만에 백그라운드에서 자동으로 양방향 동기화(반영/가져오기)가 실행**됩니다. 디데이 마커(`[0]` 등) 및 우선순위 자동 정렬도 이 순간 즉시 처리됩니다.

### ✏️ 빠른 할 일 캡처 버튼 (연필 아이콘)
*   **기능**: 어디서든 팝업 창을 띄워 메모를 추가하면, 스케줄 노트의 `# Todo` 섹션으로 자동 주입 및 정렬됩니다. 다중 창(새 창 띄우기) 환경에서도 완벽히 작동합니다.

### 🌤️ 하루 리셋 및 마감 버튼 (구름 아이콘)
*   **기능**: 회고 창을 작성하고 제출하면, 루틴 체크 내용을 월간 표로 누적하고 기존 체크박스는 빈 상태(`[ ]`)로 리셋 시켜 다음 날을 준비합니다.

### 🗂️ 통계 수동 아카이빙 버튼 (폴더 아이콘)
*   **기능**: 10일 구간 통계 그래프를 수동으로 강제 갱신/저장할 때 사용합니다.

### 📤 개별 프로젝트 스케줄 반영 (자동화 됨)
*   **어디서 동작하나요?**: **각 개별 프로젝트 노트** 내부
*   **기능**: 과거에 쓰이던 내보내기 버튼은 폐지되었습니다. 프로젝트 노트에서 짠 계획들을 수정한 뒤 **다른 탭(창)을 클릭하거나 포커스를 이동하기만 하면, 즉시 메인 스케줄 노트로 실시간 푸시(Push) 동기화**가 작동합니다.

## 🛠️ 3. 스케줄 노트 수정 권한 (커스텀 가이드)

플러그인이 자동으로 문서를 썼다 지웠다 하기 때문에, "절대 건드리면 안 되는 이정표(헤더)"와 "사용자가 마음대로 커스텀해도 되는 곳"이 명확히 구분됩니다.

### ⛔ [절대 금지] 건드리면 고장 나는 부분
이 부분들은 플러그인이 인식하는 표지판입니다. 글자나 띄어쓰기가 바뀌면 플러그인이 길을 잃습니다.
1. **대분류 헤더 이름들**: `# Todo` (또는 `#### 할 일`), `# Routine` (또는 `# 루틴`), `# Checklist` (또는 `# 체크리스트`), `# Statistics` (또는 `# 통계`), `# Plan` (또는 `# 계획`), `# Execution` (또는 `# 실행`) 등
2. **블록 아이디 (`^xxxxxx`)**: 동기화를 위한 고유 식별자.
3. **표의 뼈대 기호 (`|`)**: 파이프 기호를 지우면 통계 누적이 불가합니다.

### ✅ [자유 수정] 내 마음대로 바꿔도 되는 부분
표지판과 식별자만 건드리지 않는다면, 그 안의 '내용물'은 100% 당신의 마음대로 커스텀 가능합니다.
1. **루틴 표의 '열(항목) 이름' 맘대로 바꾸기**: 상단 미니 표와 하단 마스터 표의 이름만 똑같이 맞춰주면, '독서', '명상' 등으로 마음대로 고쳐도 플러그인이 알아서 인식하고 통계를 쌓습니다.
2. **할 일 내용과 체크 상태 자유 변경**: 내용을 수정하거나 체크 박스 안에 `x`, `-`, `>` 등을 넣어도 완벽하게 인식됩니다.
3. **`# 루틴` 콜아웃 내부의 텍스트**: 명언이나 목표 텍스트들은 마음대로 지우거나 고쳐 써도 지장 없습니다.
4. **할 일의 위치(순서) 이동**: 각 할 일 끝에 `^식별자`만 온전히 달려있다면 순서를 마음대로 바꿔도 문제 없이 동기화됩니다.
5. **[NEW] ⬆️ 실행으로 복사 버튼 지원**: 프로젝트의 `# 계획` 탭에서 태스크 옆에 나타나는 ⬆️ 버튼을 클릭해 메인 스케줄 노트와 즉시 연동되는 `# 실행` 탭으로 간편하게 태스크를 올려보낼 수 있습니다!

## 🎨 4. 나만의 루틴(표) 커스텀하기 (상세)

**[핵심 꿀팁: 상단 표와 하단 표 분리 운영]**
스케줄 노트를 보면 **① 제일 상단의 얇은 미니 표(입력용)**와, 맨 밑의 **② `# 체크리스트` 거대한 마스터 표(통계 보관용)** 두 개가 있습니다.
*   **칸 수를 맞출 필요가 전혀 없습니다!** 플러그인이 이름표(헤더)를 읽고 알아서 똑똑하게 매칭하여 데이터를 옮겨줍니다.
*   **추천 세팅**: 매일 눈으로 봐야 하는 ① 상단 미니 표는 '독서', '운동' 등 핵심 3~4개 칸만 남겨서 얇게 쓰시고, ② 하단 마스터 표에는 가끔씩 체크하는 '영양제', '병원' 등의 칸을 10개씩 길게 늘려서 보관하셔도 완벽하게 연동됩니다.

### 📅 기한(D-Day) 자동 계산과 하향 전파
*   할 일 뒤에 `📅 2026-06-10` 처럼 달력 이모지와 날짜를 적어두고 탭 전환이나 동기화를 수행하면 플러그인이 기한 마커(`- [3] 책 읽기`)를 자동으로 달아줍니다. (현재는 팝업 캘린더 위젯 지원으로 더욱 편하게 입력 가능)
*   **[핵심]**: 부모 태스크에 기한이 걸려있으면, 그 아래 들여쓰기 된 자식 태스크들도 부모의 기한을 똑같이 물려받습니다!

### 🎯 [NEW] 더욱 강력해진 긴급도 정렬
부모 작업 자체의 마감일뿐만 아니라 하위 자식 작업들의 기한까지 종합적으로 탐색하는 **상향 전파(Upward Propagation)** 엔진이 탑재되었습니다. 프로젝트 하위 작업 중 하나라도 기한이 급한 것이 있다면, 전체 그룹이 상단으로 스마트하게 끌어올려집니다.

## 🚨 6. 자주 묻는 질문 (FAQ) 및 에러 해결

*   **Q. 하루 리셋을 눌렀는데 에러가 떴다고 나옵니다!**
    *   **A.** 스케줄 노트 내부의 헤더(예: `# Todo`) 이름이 훼손되었을 가능성이 큽니다. 에러가 나더라도 플러그인의 **'트랜잭션 롤백'** 기능이 작동하여 파일을 리셋 직전 원본 상태로 완벽히 되돌려 놓습니다. 헤더 이름 확인 후 다시 시도해 주세요.
*   **Q. 과거의 Templater 스크립트(.js, .md 파일들)는 지워도 되나요?**
    *   **A.** 네! 완전히 지우셔도 됩니다. 플러그인이 모든 기능을 더 빠르고 안전하게 대체합니다.
*   **Q. 표를 수정하다가 모양이 깨졌어요.**
    *   **A.** 옵시디언 표는 `|` 기호로 칸이 구분됩니다. 표를 수정하실 때 `|` 기호가 지워지지 않도록만 주의해 주세요.
*   **Q. 팝아웃(새 창 열기) 모드에서 써도 되나요?**
    *   **A.** 네! 이번 1.0.52 업데이트를 통해 팝아웃 창 환경에서도 단축키 이벤트와 동기화 엔진이 100% 정상 구동되도록 완벽히 개선되었습니다. 마음껏 창을 분리해서 사용하세요.
