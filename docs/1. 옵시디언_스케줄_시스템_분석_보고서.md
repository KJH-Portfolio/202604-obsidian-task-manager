# 옵시디언 스케줄 및 태스크 관리 시스템 분석 보고서

> [!NOTE] 📦 보관 문서 (이식 완료 및 고도화)
> 이 문서는 **MyWorld Task Manager** 플러그인의 개발 이전, Templater 스크립트와 CSS 스니펫 기반으로 운영되던 구버전 시스템을 분석한 보고서입니다.
> **2026년 6월 최신 버전(v1.0.52) 기준, 아래에 기술된 모든 기능은 완벽하게 내장되었을 뿐만 아니라, 팝아웃(멀티 윈도우) 지원 및 라이브 프리뷰 최적화 등 훨씬 고도화된 시스템으로 발전했습니다.**
> 이 문서는 개발 히스토리 및 레거시 구조 참고를 위해 보관합니다.

이 보고서는 사용자님의 옵시디언(Obsidian) 보관소에 구축되어 있던 스케줄 관련 시각적 스타일(CSS) 및 기능적 자동화 스크립트(Templater/TaskUtils.js)의 전체 구조와 작동 원리를 정리한 문서입니다.

---

## 1. 시각적 UI 및 가독성 개선 기능 (CSS snippets)

사용자님의 스케줄과 할 일 항목들을 보기 좋게 렌더링하기 위해 총 2개의 핵심 CSS 스니펫이 역할을 분담하여 작동하고 있습니다.

### ① 스케줄 마감 긴급도 하이라이트 (`fix-task-indent.css`)
*   **해결하는 문제**: 텍스트 상에 지저분하게 드러나는 태그들 대신 커스텀 마커(`[0]`, `[1]`, `[!]` 등)을 깔끔하게 숨기면서, 동시에 마감 기한의 긴급성을 즉시 인지하도록 돕습니다.
*   **동작 원리**: 
    *   디데이 관련 태그들을 화면에서 숨김(`font-size: 0`, `opacity: 0`) 처리합니다.
    *   대신 해당 태그가 포함된 할 일 줄(li 또는 cm-line) 왼쪽에 **6px 두께의 굵은 세로 컬러 바 마커**와 은은한 배경 그라데이션을 입혀 시각적으로 강조합니다.
        *   `#Past` (기한 지남): 다크 레드
        *   `[0]` (오늘 마감): 빨간색
        *   `[1]` (내일 마감): 노란색
        *   `[2]` (D-2 마감): 초록색
        *   `[3]` (D-3 마감): 파란색
        *   `[7]` (D-7 이내): 회색
    *   콜아웃 내부의 스케줄에도 색상 충돌 없이 깔끔하게 컬러 바가 표시되도록 보정하며, 할 일이 완료되면 하이라이트 배경을 자동으로 제거합니다.

### ② 가로형 가로 칩 버튼 UI (`inline-routine.css`)
*   **해결하는 문제**: 루틴이나 반복 작업 리스트가 세로로 길게 늘어져 화면 공간을 차지하는 현상을 방지합니다.
*   **동작 원리**:
    *   오직 `> [!routine]` 형식의 전용 콜아웃 상자 내부의 리스트만 타겟팅합니다.
    *   세로 목록 형태의 태스크들을 둥근 **가로형 버튼(Badge/Chip)** 형태로 레이아웃을 전환(display: inline-flex)합니다.
    *   **[최신 업데이트]**: 라이브 프리뷰(Live Preview) 모드에서 CodeMirror 에디터의 보이지 않는 레이어와 겹쳐 클릭이 잘 안 되던 문제를 해결하기 위해, 체크박스 영역의 `z-index`와 `pointer-events` 속성을 최적화하여 클릭 사용성을 대폭 개선했습니다.
    *   할 일 상태에 따른 맞춤형 스타일을 부여합니다.
        *   **완료(`x`)**: 투명도 `0.4` + 취소선
        *   **취소(`-`)**: 투명도 `0.5` + 빨간색 배경/테두리 + 취소선
        *   **진행중(`/`)**: 투명도 `0.5` + 노란색 배경/테두리 + 취소선

> **→ 현재 이식 상태**: 플러그인의 `styles.css`로 완전히 통합되었으며, 멀티 윈도우(새 창 열기) 환경에서도 스타일과 위젯 렌더링이 깨지지 않도록 완벽하게 동기화되었습니다.

## 2. 태스크 및 프로젝트 동기화 엔진 (TaskUtils.js)

모든 동작형 스케줄 스크립트들을 지탱하는 공통 비즈니스 로직 라이브러리(`TaskUtils.js`)입니다. 데일리 노트와 프로젝트 노트 간의 양방향 싱크 및 정렬, 통계를 모듈화하여 관리합니다.

*   **중앙 관리형 정규식 (`REGEX`)**: 블록 ID 분리(`^id`), 완료 상태(`[x]`, `[X]`, `[-]`만 완료/종결로 인정), 📅 날짜 라벨 등을 파싱하기 위한 통합 규칙.
*   **마커 자동 할당 및 전파 (`applyMarkersToLines`)**: 📅 날짜가 붙은 할 일을 오늘 기준 날짜 차이로 연산하여 디데이 마커(`[0]` 등)를 자동 부여합니다. 부모 태스크의 날짜 마커를 자식 태스크들에 전파하며, 부모가 완료/취소 상태가 되면 모든 자식들까지 일괄 완료/취소 처리하는 하향 전파(Downward)를 탑재하고 있습니다.
*   **할 일 정렬 알고리즘 (`sortTaskTree`)**: `# Todo` 등의 섹션을 트리 구조로 변환한 뒤, **긴급도 마커 우선순위(`MARKER_PRI`) → 마감 날짜 순**으로 자동 정렬합니다. 빈 줄은 계층 구조 맨 아래로 보내고, 부모 할 일 밑에 적어둔 일반 메모나 빈 줄이 정렬 도중에 낙오되지 않도록 묶어 이동시키는 청크(Chunk) 보존 로직이 특징입니다.
*   **[최신 업데이트] 프로젝트 양방향 싱크 엔진**: 작성일/수정일 자동 갱신 로직이 강화되었으며, 데일리 노트와 개별 프로젝트 노트 간의 색인(Indexing) 알고리즘이 수정되어 오늘 할 일 목록 추출의 정확도가 높아졌습니다. 데일리 노트의 `# Project` 섹션(대시보드)과 실제 개별 프로젝트 파일의 `# 실행`, `# 계획` 섹션 간 상태를 양방향으로 자동 동기화합니다. 블록 ID가 없는 할 일에는 고유 6자리 ID를 자동 부여하여 추적성을 유지하며, 완전 소거(`//`) 기능도 안정적으로 작동합니다.

> **→ 현재 이식 상태**: 모든 로직은 TypeScript 기반의 플러그인 엔진으로 이식 완료되었으며, 옵시디언의 최신 API 구조에 맞춰 다중 창(팝아웃) 환경에서의 비동기 안정성이 대폭 강화되었습니다.

## 3. 마감 및 자동화 템플릿 (Templater Scripts)

과거 Templater 설정을 통해 사용자 스케줄 관리 주기(수시, 하루 마감, 프로젝트 단위 반영 등)에 따라 호출되던 스크립트 파일들의 역할 분석입니다. 현재는 모두 플러그인 엔진 및 명령어로 완전히 대체되었습니다.

### ① 수시 동기화 (`98.task_manage.md`)
*   **호출 시기**: (과거) 데일리 노트 작성 중 태스크 동기화가 필요할 때 수시로 실행
*   **동작 흐름**:
    1.  데일리 노트의 프로젝트 섹션 내 변경 사항을 스캔합니다.
    2.  변경된 태스크 상태를 실제 프로젝트 노트에 반영합니다.
    3.  역으로 프로젝트 노트의 최신 할 일 상태를 수집해 데일리 노트의 `# Project` 대시보드와 `#### 프로젝트` 섹션을 갱신합니다.
    4.  데일리 노트의 `# Todo` 섹션 내 할 일들을 마감 순으로 자동 정렬합니다.
> **→ 현재 이식 상태**: 과거에 존재했던 수동 버튼(⚡️)은 **완전히 폐지**되었으며, 위 4단계 동작 흐름은 100% **백그라운드 자동 동기화(Background Auto-Sync)** 로 대체되었습니다. 사용자가 노트를 수정한 뒤 탭을 전환(`active-leaf-change`)할 때마다 플러그인이 변경 사항을 감지하여 알아서 동기화를 수행하므로 수동 조작이 불필요합니다. (명령어 팔레트를 통한 수동 호출 기능만 내장되어 있습니다.)

### ② 일간 마감 및 데일리 리셋 (`99.Daily_task_reset.md`)
*   **호출 시기**: 하루 일과를 마감하고 다음 날로 넘어가는 밤/새벽 시간에 실행
*   **동작 흐름**:
    1.  데일리 노트의 오늘 루틴 기록표(미니 테이블)를 정렬하여 월간 통계 테이블(체크리스트 섹션)로 이관 및 누적합니다.
    2.  오늘의 회고와 내일의 도전 목표(Step)를 팝업창으로 입력받아 주간 아카이브에 기록합니다.
    3.  데일리 노트를 리셋합니다 (`> [!routine]` 내의 모든 둥근 버튼식 루틴 빈 상태로 초기화, 프로젝트 할 일 중 이미 완료된 항목들 소거 및 대시보드 렌더링).
    4.  오늘의 루틴 달성 데이터를 토대로 세그먼트 통계 대시보드를 생성하여 `# 통계` 섹션에 삽입합니다.
> **→ 현재 이식 상태**: 플러그인 명령어 **`daily-task-reset`** (`🌤️` 버튼)으로 대체. 에러 발생 시 롤백 기능(Transaction Rollback)이 내장되어 파일 파괴를 방지합니다.

### ③ 프로젝트 단위 스케줄 반영 (`102.Push_Project_to_Schedule.md`)
*   **호출 시기**: (과거) 개별 프로젝트 노트를 작성하다가 메인 스케줄에 상태를 반영할 때 수동 실행
*   **동작 흐름**:
    1.  현재 열려 있는 프로젝트 노트의 `# 실행` 섹션(현재 태스크)의 상태를 `# 계획` 섹션(전체 로드맵)으로 In-place 동기화합니다.
    2.  두 섹션 간 완료/추가 상태를 비교해 총 계획 대비 완료율을 계산하고 진행도 프로그레스 바를 그립니다.
    3.  `# 실행` 섹션에서 이미 완료 처리된 태스크를 소거해 프로젝트 본문을 깨끗하게 유지합니다.
    4.  최종 갱신된 결과를 메인 스케줄 파일의 프로젝트 대시보드 영역에 실시간 덮어씌웁니다.
> **→ 현재 이식 상태**: 과거 개별 프로젝트 노트에 존재했던 수동 버튼(📤)은 **완전히 폐지**되었으며, 이 기능 역시 100% **백그라운드 자동 동기화 엔진**으로 통합되었습니다. 프로젝트 노트를 편집 후 탭을 전환하면(`active-leaf-change`) 플러그인이 알아서 메인 스케줄 대시보드로 변경 사항을 푸시(Push)합니다.

### ④ 월간 통계 아카이브 (`103.Monthly_stats_archive.md`)
*   **호출 시기**: 월간 기록 마감 및 통계 분석이 필요할 때 실행
*   **동작 흐름**:
    1.  데일리 노트 내 한 달 분량의 체크리스트 표를 분석하여 이모지 마커(`🟦`, `🟩`, `🟨`, `🟥`) 개수를 집계합니다.
    2.  집계된 수치를 활용해 10일 단위(1, 2, 3구간) 누적 가로막대 HTML 그래프 대시보드를 생성합니다.
    3.  이를 연도/월별 폴더 구조를 갖춘 아카이브 파일(`4. Archive/98.Schedule/...`)에 누적 저장하고, 데일리 노트의 `# 통계` 및 루틴 내 취약 항목 볼드 강조를 갱신합니다.
> **→ 현재 이식 상태**: 플러그인 명령어 **`monthly-stats-archive`** (`🗂️` 버튼)으로 대체되었습니다.
