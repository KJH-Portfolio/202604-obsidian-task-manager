# 9. MyWorld Task Manager - 플러그인 검증(QA) 가이드

이 문서는 개발 완료된 **MyWorld Task Manager** 플러그인(v1.0.52 이상)을 철저하게 검증(테스트)하기 위한 품질 검증(QA) 전용 시나리오 문서입니다.
플러그인을 업데이트하거나 소스 코드를 변경했을 때, 오류가 발생하지 않는지 아래의 13대 시나리오를 바탕으로 점검합니다.

---

## 1. 프로젝트 검증 가이드 (Verification Manual)

플러그인이 정상 작동하는지 확인하기 위해 아래의 **빌드 검증 -> 비주얼 검증 -> 기능별 13대 시나리오 검증**을 순서대로 수행합니다.

### ① 빌드 결과물 검증
플러그인 루트 폴더(`개발 프로그램/`)에서 다음 파일 3종이 생성되었는지 확인합니다:
- `main.js`: esbuild를 통해 번들링된 플러그인 소스코드
- `manifest.json`: 최신 버전이 명시된 메타데이터
- `styles.css`: 루틴 버튼화 및 D-Day 긴급도 컬러 바 스타일

### ② 비주얼 렌더링 검증
옵시디언에서 플러그인을 활성화한 후, 데일리 스케줄 노트를 열어 다음 스타일이 적용되는지 검증합니다:
1. **루틴 버튼화 및 라이브 프리뷰 포커스**: `> [!routine]` 콜아웃 내의 목록들이 둥근 가로형 버튼으로 정렬되며, **라이브 프리뷰 상태에서도 체크박스 클릭이 원활히 작동**하는지 확인합니다.
2. **D-Day 긴급도 세로 컬러 바**: 할 일에 작성된 커스텀 마커들이 숨겨지며, 해당 할 일 줄 왼쪽에 은은한 컬러 마커 바가 렌더링되는지 확인합니다. (읽기 모드에서도 동일하게 렌더링되어야 함)

### ③ 기능별 14대 시나리오 검증

*   **시나리오 1. 부팅 시 동기화 모달 (StartupSyncModal)**
    - 옵시디언을 처음 켰을 때(또는 플러그인을 껐다 켰을 때), 아직 동기화되지 않은 전날의 내역이 있다면 화면 중앙에 부팅 모달 창이 부드럽게 팝업되며 동기화를 안내하는지 확인합니다.
*   **시나리오 2. 캘린더 팝업 위젯 동작 검증 (Calendar Widget)**
    - 할 일 끝에서 캘린더 아이콘 버튼을 눌렀을 때 데이트 피커(달력) UI가 팝업되며, 날짜 선택 시 텍스트 본문에 즉각 반영되고 디데이 마커가 갱신되는지 확인합니다.
*   **시나리오 3. 다중 창(Popout) 렌더링 및 키 이벤트 검증**
    - 스케줄 노트를 새 창(Open in new window)으로 띄운 후 동기화 버튼 클릭이나 빠른 할 일 캡처 창 띄우기가 정상 작동하는지, 그리고 팝아웃 창에서 ESC 키를 눌러 모달이 정상적으로 닫히는지(이벤트 누수 방지) 확인합니다.
*   **시나리오 4. 스케줄 파일 생성 (`create-today-schedule`)**
    - 설정된 `mainSchedulePath` 경로에 31일까지의 루틴 뼈대 및 동적 치환자(`{{date}}`, `{{currentDay}}` 등)가 성공적으로 매핑되어 파일이 생성되는지 확인합니다.
*   **시나리오 5. 새 프로젝트 생성 (`create-new-project`)**
    - 모달 창에 프로젝트명을 입력했을 때 지정 프로젝트 폴더 내부에 양식이 복사 생성되고, 해당 파일이 즉시 활성화(열기)되는지 확인합니다.
*   **시나리오 6. 스케줄 즉시 이동 (`open-memo`)**
    - 단축 링크 또는 명령어를 수행할 때 현재 작업 중인 노트와 무관하게 설정된 메인 스케줄 노트가 즉시 활성 화면으로 포커싱되는지 확인합니다.
*   **시나리오 7. 빠른 할 일 캡처 (`quick-capture`)**
    - 입력창에 메모를 넣었을 때, 메인 스케줄 노트의 `# Todo` -> `#### 할 일` 아래에 체크박스(`- [ ]`) 상태로 즉시 추가 및 기한에 맞춰 실시간 재정렬되는지 확인합니다.
*   **시나리오 8. 프로젝트 스케줄 반영 (`push-project-to-schedule`)**
    - 개별 프로젝트 노트에서 실행할 때, `# 실행` 섹션의 내용이 `# 계획` 섹션의 앵커 ID와 동기화되며, 진행률 프로그레스 바가 그려지고, 완료 항목이 소거되며, 결과가 메인 스케줄 파일의 `# Project` 대시보드에 정상 덮어씌워지는지 확인합니다. (현재는 자동화 엔진이 백그라운드에서 수행함)
*   **시나리오 9. 양방향 수시 동기화 (`task-manage`)**
    - 메인 스케줄 노트의 대시보드 상에서 할 일 항목의 체크박스를 변경한 후 탭을 전환했을 때, 변경된 데이터가 실제 개별 프로젝트 노트의 `# 실행` 및 `# 계획` 섹션에 완벽히 이식되는지 확인합니다. (현재는 수동 ⚡️ 버튼 없이 자동화 됨)
*   **시나리오 10. 작성일/수정일 인덱싱 (Date Indexing)**
    - 프로젝트 파일 동기화 시, 옵시디언 프로퍼티(Frontmatter)의 `수정일` 텍스트가 내부 로직에 의해 자동으로 최신 날짜 및 시간으로 갱신되는지 확인합니다.
*   **시나리오 11. 하루 루틴 리셋 및 기록 이관 (`daily-task-reset` / 🌤️ 버튼)**
    - 모달 창에 회고 및 내일의 Step을 입력 후 제출하면, 오늘의 루틴 체크 목록이 미니 테이블에서 월간 체크리스트 표로 누적 전송되며, 아카이브 파일(주간/월간)에 회고록이 작성되고, 오늘의 루틴 버튼들이 다시 빈 박스(`[ ]`)로 리셋되는지 검증합니다.
*   **시나리오 12. 수동 아카이브 및 10일 통계 갱신 (`monthly-stats-archive` / 🗂️ 버튼)**
    - 스케줄 노트의 체크리스트 표를 분석하여 10일 구간별(1구간, 2구간, 3구간) 누적 HTML/CSS 그래프가 갱신되어 메인 스케줄 `# 통계` 섹션과 `4. Archive/98.Schedule/...` 월간 일지에 정상 반영되는지 확인합니다.
*   **시나리오 13. PARA 및 제텔카스텐 지식 관리 구조 셋업 헬퍼 검증**
    - 설정 화면의 `2. 지식 관리 시스템 구축 헬퍼` 영역에서 버튼 클릭 시 `0. Inbox`, `1. Project`, `5. Zettelkasten/01.Fleeting` 등의 폴더 트리와 가이드 문서가 보관소 내에 일괄 생성되는지 확인합니다.
*   **시나리오 14. 템플릿 모달 팝업 및 동적 경로 입력 검증 (`TemplatePathModal`)**
    - 설정 화면의 `3. 기본 환경 및 파일 생성 헬퍼` 영역에서 템플릿 생성 버튼을 눌렀을 때, 고정 경로가 아닌 모달 입력창이 뜨는지, 그리고 입력한 임의의 경로 내에 노트 양식 파일들이 정확히 렌더링(생성)되는지 확인합니다.
